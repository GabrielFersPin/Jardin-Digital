## 📝 Captura principal

> [!tip] Lo más importante
> AWS Direct Connect es un servicio para conectar tu red on‑prem (tu oficina/data center) con AWS usando una conexión dedicada en vez de hacerlo solo por Internet.


### 🎯 Detalles / Contenido

En lugar de acceder a AWS a través de Internet, el tráfico utiliza una conexión física o lógica dedicada hacia una ubicación de Direct Connect.

Se utiliza, por ejemplo, para:

- Conectar un centro de datos local con una VPC.
- Acceder desde la red corporativa a EC2, RDS, S3 u otros servicios de AWS.
- Transferir grandes volúmenes de datos de forma más constante.
- Reducir la dependencia de Internet.
- Obtener menor latencia y mayor estabilidad que una conexión VPN por Internet.
- Crear arquitecturas híbridas entre on-premises y AWS.
